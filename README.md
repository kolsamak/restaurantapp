# كل سمك — الموقع التعريفي

موقع عربي RTL بسيط ومتجاوب لعلامة **كل سمك**.

## الملفات
- `index.html` الصفحة الرئيسية
- `about.html` من نحن
- `privacy.html` سياسة الخصوصية
- `terms.html` شروط الاستخدام
- `delete-account.html` واجهة طلب حذف الحساب
- `styles.css` تنسيقات التصميم
- `script.js` التفاعلات البسيطة
- `assets/logo.jpg` شعار العلامة

## التشغيل
افتح `index.html` مباشرة في المتصفح أو استخدم Live Server.

## النشر عبر GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح Settings → Pages.
3. اختر النشر من الفرع الرئيسي (`main`) ومجلد الجذر (`/ root`).
4. احفظ وانتظر ظهور رابط الموقع.

## تنبيه بخصوص نموذج حذف الحساب
نموذج طلب الحذف في هذه النسخة واجهة تجريبية فقط؛ يعرض رسالة مراجعة على المتصفح ولا يرسل البيانات إلى خادم. لتفعيل استقبال الطلبات، يلزم ربطه بخدمة خلفية آمنة أو مزود نماذج.

## بيانات الخصوصية
نص السياسة يذكر البيانات المقدمة يدويًا: الاسم ورقم الهاتف والعنوان فقط. لا يذكر جمع البريد الإلكتروني أو بيانات GPS.
